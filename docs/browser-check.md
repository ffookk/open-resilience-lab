## 复现方法

1. 按 README 的演示命令生成虚构 HTML。
2. 在独立浏览器配置中断网打开本地文件，检查标题、联系人、集合安排、家庭成员、备注与来源栏目。
3. 分别以桌面与窄屏视口查看，并检查是否有水平滚动或内容裁切。
4. 使用浏览器打印到 A4 PDF，关闭页眉页脚，检查每页内容、分页和可提取文字。
5. 如保存截图或 PDF，只使用虚构样例，放入被忽略的本地目录，不提交个人预案。
